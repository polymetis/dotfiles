# Rebuild — 2026-06-08

Rebuilt these dotfiles from a long-stale [holman/dotfiles](https://github.com/holman/dotfiles)
fork (last touched 2024) into a clean, chezmoi-managed, secret-free setup that
both a personal and a work machine can pull. This note records the decisions and
the verification; the [README](../../README.md) covers day-to-day usage.

## Decisions

| Fork | Choice | Why |
|------|--------|-----|
| Manager | **chezmoi** | Per-machine templating + an untracked secrets file solve the "can't share data between work and personal" constraint directly. |
| Terminal | **Ghostty** | Best-in-class Nerd-Font fallback and cursive-italic handling; plain-text config that lives in the repo. |
| Nerd glyphs | **Runtime fallback** | Keep Operator Mono pristine (no patching); the terminal merges in glyphs at render time. Survives font updates. |
| Ligatures | **None** | Operator Mono has no ligatures, so the old VS Code `fontLigatures: true` was a no-op. Its cursive italics are the feature. |

## The font / cursive pipeline

Operator Mono SSm is proprietary, so it is **not** in this repo — `run_once_after_20-fonts.sh`
copies it from `~/operator mono` into `~/Library/Fonts`. The cursive italics come
from three things lining up:

1. **Ghostty** maps italic text to the cursive face: `font-style-italic = Book Italic`
   (verified with `ghostty +show-config` / `+show-face`).
2. **Neovim** (tokyonight) marks the right groups italic — `@comment`, `@keyword`,
   `@module` — while keeping `@string.documentation` / `@comment.documentation`
   upright, mirroring the old VS Code `tokenColorCustomizations` for Elixir.
3. **tmux** passes italics + truecolor through (`tmux-256color` + `terminal-features ",*:RGB"`).

Nerd icon glyphs resolve via Ghostty's runtime fallback (built-in JetBrains Mono
Nerd, with `Symbols Nerd Font Mono` as an explicit secondary).

## Verification

Rendered a sample Elixir module in nvim inside Ghostty and confirmed visually:

- line comments, `def`-block keywords, and module names → **Operator cursive italic**
- `@moduledoc` / `@doc` heredocs → **upright** (the intended exception)
- treesitter parsers `elixir` / `heex` / `eex` present; colorscheme `tokyonight-night` active

Highlight attributes were also checked headlessly (`nvim_get_hl`): `@comment`,
`@keyword`, `@module` all `italic=true`; `@string.documentation` not italic.

## What changed from the old setup

- **fish → zsh** (login shell). The old fish config was thin (just `mise activate`
  + a couple of env vars); nothing meaningful was lost. fish config left in place.
- **git aliases → `git-*` scripts** in `~/.local/bin` (the preferred pattern).
- **rbenv → mise**, **pathogen vim → LazyVim**, **nord tmux theme → tokyonight**.
- Secrets (`VAULT_ADDR`, etc.) moved out of shell rc into untracked
  `~/.config/zsh/local.zsh`.
- Fixed a stray leading quote that had been in the git author name.

## bin/ triage

- **Kept:** `git-undo/up/promote/credit/amend/track/all`, `e`, `spark`, `extract`.
- **Restored later** (initially dropped): `clock`, the `git-modules` set
  (`git-modules` + `clone`/`ls`/`messaging`/`remove`) and its
  `absolute-to-relative-directory` dependency.
- **Dropped:** `gitio` (git.io shut down 2022), `git-wtf` & `git-rank-contributers`
  (Ruby; latter is GPL), `dot` (chezmoi + brew bundle replace it), and assorted
  holman-personal scripts.

Two restored scripts carry pre-existing quirks, left verbatim: `git-modules-remove`
uses an invalid `git commit -u`, and `absolute-to-relative-directory` has a
`[ -n "$x"]` spacing bug.
